# Developer documentation

For contributors and maintainers working on Tool Inspector:

- [Development](Development): local builds, the TUI-only package shape and compatibility checks.
- [Publishing](Publishing): trusted publisher setup and the release workflow.

The plugin's state machines are documented in [docs/state-machines.md](https://github.com/lunchbox-labs/opencode-tool-inspector/blob/main/docs/state-machines.md). These wiki pages are published from [docs/wiki](https://github.com/lunchbox-labs/opencode-tool-inspector/tree/main/docs/wiki) on every push to `main`; change them there.

The repository's [AGENTS.md](https://github.com/lunchbox-labs/opencode-tool-inspector/blob/main/AGENTS.md) and linked shared standards remain the authoritative machine instructions. [User documentation](Home#user-documentation) covers installation and everyday use.
