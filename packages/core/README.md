# Tool Inspector core

Internal source shared by the [Tool Inspector](https://github.com/lunchbox-labs/opencode-tool-inspector) host packages, `@lunchbox-labs/opencode-tool-inspector` and `@lunchbox-labs/kilo-tool-inspector`. It is private and never published: each host package's tsdown build bundles it at build time. Its API isn't stable.

The [Developer](https://github.com/lunchbox-labs/opencode-tool-inspector/wiki/Developer) wiki page describes the layout and build.
