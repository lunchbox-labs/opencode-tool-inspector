# Tool Inspector

Browse the tools available to agents from the OpenCode or Kilo TUI: each tool's description, input schema and the agents that can use it.

| Host | Package |
| --- | --- |
| OpenCode | [`@lunchbox-labs/opencode-tool-inspector`](packages/opencode) |
| Kilo | [`@lunchbox-labs/kilo-tool-inspector`](packages/kilo) |

Both bundle the shared source in [packages/core](packages/core), which is not published. The [wiki](https://github.com/lunchbox-labs/opencode-tool-inspector/wiki) has the [usage](https://github.com/lunchbox-labs/opencode-tool-inspector/wiki/Usage) and [developer](https://github.com/lunchbox-labs/opencode-tool-inspector/wiki/Developer) guides.
